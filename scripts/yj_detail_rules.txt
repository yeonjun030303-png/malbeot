
[디테일 보강 규칙 - 위 규칙과 충돌하면 위 규칙이 우선. 출력은 여전히 JSON만]
아래 규칙은 JSON 안의 scenes / bg / chat / extras 문자열에 녹여서 쓴다. 사용자가 적지 않은 작은 디테일은 네가 매번 스스로 채운다. 채운 뒤 "너무 깨끗하지 않은가? 빠진 디테일 3개를 더 찾았는가?"를 스스로 점검한다. 광고 사진 같은 깨끗함과 완벽한 대칭은 금지한다. 결과물은 사원이 몰래 찍은 실제 사진 같은 질감과 분위기로 연출한다.

1. 공통
- scenes와 bg에는 읽히는 글자를 넣지 않는다(이미지 AI는 한글을 깨뜨린다). 읽히는 글자는 doc / chat / extras로 따로 만들어 합성한다.
- 인물 얼굴은 노출하지 않는다. 사람이 필요하면 뒤통수, 어깨선, 손, 팔뚝만 묘사한다. bg에는 사람을 넣지 않는다(no people).
- 실존 기업명, 실존 인물, 실제 직인, 실제 전화번호는 쓰지 않는다. 이름·부서·번호는 전부 네가 지어낸 가상의 것만 쓴다(휴대폰은 010-****-**** 처럼 마스킹, 내선번호는 3자리).

2. 폰 화면을 몰래 촬영한 장면 (단톡방 캡처)
- 기기: 최신 아이폰 프로급 기종(다이나믹 아일랜드, 티타늄 프레임, 후면 카메라 배열이 보이는 각도). 케이스는 하나로 정하고 모서리 마모, 홈에 낀 먼지를 넣는다.
- 액정: 한쪽 모서리에서 뻗은 머리카락 굵기의 금 2~3줄(빛에 하얗게 반짝), 지문·기름 번짐, 먼지 알갱이, 필름 가장자리 기포.
- 촬영 광학: 화면 재촬영 모아레, 화면 과노출 블룸, 유리에 반사된 플래시 핫스팟 한 곳, 렌즈 플레어, 약한 색수차, 모서리 비네팅, 높은 ISO 노이즈, 약간의 손떨림, 5~12도 기울어진 구도.
- 폰 바깥 배경은 장면마다 하나를 구체적으로 고른다: 밤 안방 협탁(어두운 방, 플래시만 빛, 충전 케이블, 안경, 물컵, 이불 주름) / 청바지 무릎 위(데님 결, 색바램, 리벳, 실밥) / 어수선한 책상(나무 결, 볼펜 자국, 영수증, 리모컨). 살림 냄새가 나게 쓰고 배경은 어둡거나 초점을 뺀다.
- 카톡 화면: 상태바 시간·신호·배터리 %와 대화 시각이 모순되지 않게, 스크롤 중간에서 잘린 말풍선, 하단 입력창, 상대 말풍선 흰색·내 말풍선 노란색·배경 하늘색, 방 이름 옆 참여 인원 수.

3. 회의실/발표 장면
- 빔프로젝터 화면 재촬영 특유의 스캔라인과 색 번짐, 탁자 위 인쇄물·종이컵 커피·노트북·리모컨·물병이 어수선하게, 형광등은 약간 푸르스름.
- 사람이 보이면 뒤통수와 어깨선만: 머리숱과 헤어가 사람마다 다르고, 목주름, 셔츠 깃 눌림, 첫 단추 풀림, 소매 걷음, 사원증 목걸이, 셔츠 주머니 볼펜, 손목시계 등 직급별(사원 20대 후반~부장 50대) 나이에 맞는 체형과 옷차림을 인물마다 다르게 쓴다.

4. 사내 게시판 / 대자보 장면
- 게시판 종류를 정한다(코르크, 복도 알루미늄 게시판, 유리 게시함). 압정 구멍, 뗀 테이프 자국, 누렇게 변색된 오래된 종이, 모서리 말림, 접은 자국, 삐뚤게 붙임, 겹쳐 붙임.
- 종이 질감: 흑백 복사 특유의 토너 번짐과 줄무늬, 붉은 인주 결재 도장, 손글씨 메모, 형광펜 밑줄.
- 메인 문서(doc) 주변에 실제 회사 게시판에 있을 법한 다른 게시물을 읽히는 글자로 채운다. 이 게시물들의 내용은 JSON의 "extras" 배열에 네가 직접 지어서 넣는다.

5. extras (JSON에 필드 추가)
"extras": [ { "kind": "식단표|인사발령|무재해|경조사|비상연락망|소방점검|분리수거|정수기|주차", "title": "제목", "lines": ["한 줄씩 실제 게시물 내용"], "footer": "담당 부서·내선·날짜 한 줄" } ]
- 게시판 장면이면 3~5개, 그 외에는 0~2개. 날짜는 오늘 날짜 기준으로 요일까지 맞춘다.
- 내용은 구체적이고 그럴듯하게 지어낸다. 숫자(날짜, 열량, D+일수, 내선번호)를 반드시 넣고, 서로 모순되지 않게 한다.
- 작성 예시(참고용, 그대로 복사하지 말고 매번 새로 지어낼 것):
  식단표: 제목 "주간 중식 메뉴 (10/5~10/9)", 월 "잡곡밥·김치찌개·제육볶음·콩나물무침·배추김치 / 892kcal", 화 "쌀밥·미역국·고등어구이·시금치나물·깍두기 / 845kcal", footer "원산지: 돼지고기(국내산) 쌀(국내산) / 구내식당 총무팀 내선 214"
  인사발령: 제목 "인 사 발 령", lines ["2026.10.01.자", "과장 오세진 : 자재관리팀 → 영업2팀 팀장 보임", "대리 한지훈 : 생산1팀 → 품질관리팀 전보"], footer "㈜영정철강 대표이사 (인) / 총무팀 내선 201"
  무재해: 제목 "안전제일 무재해 D+412일", lines ["보호구 착용 확인", "지게차 운행 시 일시정지"], footer "안전보건팀 내선 233"
  경조사: 제목 "부고", lines ["총무팀 최OO 과장 부친상", "빈소 : △△장례식장 2호실", "발인 : 10/3(금) 오전 7시"], footer "총무팀 내선 201"
  비상연락망: 제목 "비상연락망(3교대)", lines ["공장장 010-****-**** / 내선 301", "안전관리자 010-****-**** / 내선 233"], footer "2026.09.01. 개정"

6. bg 추가 조건
- 각 bg 묘사에 위 디테일(마모, 먼지, 얼룩, 조명 상태, 소품 3개 이상)을 넣고, 항상 "no text, no people"을 유지한다. 게시판 배경은 게시물이 붙어 있을 빈 자리(압정 구멍, 테이프 자국)를 여러 곳 남겨 두어 extras를 얹을 수 있게 한다.
